# ACTIVITY 6.1: – Check whether a number is Positive, Negative or Zero
1. Start
2. Read an integer number x from the user
3. If x is greater than 0, print Positive
4. Else if x is less than 0, print Negative
5. Else print Zero
6. Stop

# ACTIVITY 6.2: – Check whether a number is Even or Odd
1. Start
2. Read an integer number x from the user
3. If x % 2 is equal to 0, print Even
4. Else print Odd
5. Stop

# ACTIVITY 6.3: – Find the Largest of Three Numbers
1. Start
2. Read three integers X, Y, and Z from the user
3. If X is greater than or equal to Y and Z, print X as largest
4. Else if Y is greater than or equal to X and Z, print Y as largest
5. Else print Z as largest
6. Stop

# ACTIVITY 6.5: – Find Average of 3 Subjects and Display Grade
1. Start
2. Read marks of three subjects x, y, and z
3. Calculate average a = (x + y + z) / 3
4. Print the average
5. If a is greater than or equal to 90, print Grade A
6. Else if a is greater than or equal to 75, print Grade B
7. Else if a is greater than or equal to 60, print Grade C
8. Else if a is greater than or equal to 40, print Grade D
9. Else print Grade F
10. Stop

# ACTIVITY 6.6: – Check Whether a Year is Leap Year
1. Start
2. Read year x from the user
3. If the year is divisible by 400 OR divisible by 4 but not divisible by 100 then print Leap Year
4. Else print Not a Leap Year
5. Stop

# ACTIVITY 6.7: – Validate Date and Print Incremented Date
1. Start
2. Read date in dd/mm/yyyy format
3. Split the date into dd, mm, and yyyy
4. Convert day, month, and year into integers
5. Find the maximum days of the given month
6. If month is invalid or day is invalid, print Date is invalid
7. Else if date is last day of December, increment year and reset day and month
8. Else if date is last day of the month, reset day and increment month
9. Else increment the day by 1
10. Print the incremented date
11. Stop

5. Stop

# ACTIVITY 6.9: – Calculate Gross Salary of an Employee
1. Start
2. Read basic salary from the user
3. If basic salary is less than or equal to 10,000
      Calculate HRA = 20%
      Calculate DA = 80%
4. Else if basic salary is less than or equal to 20,000
      Calculate HRA = 25%
      Calculate DA = 90%
5. Else
      Calculate HRA = 30%
      Calculate DA = 95%
6. Calculate gross salary = basic + HRA + DA
7. Print gross salary
8. Stop
